# The self-hosted web fonts

Three families, all under the SIL Open Font License 1.1, downloaded from
Google Fonts and committed here so the app does not call a third party at
runtime and works offline.

| Family | Role | Licence | Upstream |
|---|---|---|---|
| Figtree | the text face | OFL 1.1 | https://fonts.google.com/specimen/Figtree |
| Fraunces | the display face | OFL 1.1 | https://fonts.google.com/specimen/Fraunces |
| Anek Bangla | Bangla | OFL 1.1 | https://fonts.google.com/specimen/Anek+Bangla |

Each `*.woff2` file has a `*.woff2.meta` file next to it recording the exact
Google Fonts URL, the weight range, the style and the unicode range it covers.
The pairs are what `scripts/fetch-fonts.mjs` writes, so the files can be
rebuilt and checked:

```sh
node scripts/fetch-fonts.mjs
```

The `@font-face` rules live in `src/app/asha-fonts.css` (the React app) and
`public/app/asha-fonts.css` (the two legacy apps). Both are generated by
`scripts/tokens.mjs`, so the faces cannot drift apart.
